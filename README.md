# Evlog Explorer

A local-first structured log explorer for [`evlog`](https://github.com/haydenbleasel/evlog), built with Nuxt 4 and Nuxt UI.

Import `.json`, `.jsonl`, or `.ndjson` files to search, filter, sort, correlate, and inspect events. Files are parsed entirely in your browser—there is no backend, upload, database, or analytics.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Checks

```bash
pnpm typecheck
pnpm lint
pnpm build
```
